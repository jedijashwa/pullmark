PullMark, documentado

Tudo o que o app faz, por escrito: um tour pelos recursos, uma referência de cada ajuste e atalho, o que cada ícone da barra lateral significa, o comando pullmark e as soluções para as poucas coisas que podem sair do trilho.

  • Recursos

    O tour guiado — leitura, revisão de diffs de PR, links e repositórios do GitHub, edição no lugar, exportação.

  • A barra lateral

    Open Files, prévias, Locations, Pull Requests, Recents — e o que cada ícone e chip significa.

  • Ajustes

    Cada controle atrás de ⌘, — General, Appearance e Keyboard — com os padrões e o que cada um muda.

  • Atalhos de teclado

    O mapa completo de teclas, incluindo quais atalhos você pode reatribuir e como.

  • Linha de comando

    O comando pullmark: arquivos, pastas, worktrees e notas para scripts.

  • Solução de problemas

    As mensagens de erro explicadas, mais os clássicos: Gatekeeper, autenticação no GitHub, Quick Look depois de uma atualização.

  • Recursos experimentais

    Recursos lançados antes de o design assentar, rotulados alfa ou beta — as notas de margem moram aqui agora, com a especificação e as instruções para agentes incluídas.

Novo por aqui?

A página inicial tem a versão curta e a instalação. O caminho de cinco minutos: instale, abra qualquer arquivo .md ou uma pasta deles, depois cole a URL de um PR do GitHub (ou só um link github.com/…/blob/…) e veja-o renderizar. O tour pelos recursos continua a partir daí.
