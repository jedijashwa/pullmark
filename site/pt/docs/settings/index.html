Abrir por Completo mantém cada arquivo que você clica. Vale para pastas locais e repositórios navegados do GitHub igualmente. Veja Prévias.

Verificar Novamente relê as credenciais — depois de gh auth login, ele conecta sem reabrir o app — e Configurar… abre um passo a passo que detecta o que falta neste Mac. Atualizações

AjusteO que faz
Mostrar Novidades depois de uma atualização Ligado (o padrão) apresenta as notas da versão depois que uma atualização chega; desligado troca por um banner discreto “Atualizado para o PullMark X” com as notas a um clique — uma atualização sempre se anuncia de algum jeito.
Updates Buscar Atualizações… sob demanda; o PullMark também verifica na abertura e periodicamente. Quando uma atualização já é conhecida, a linha oferece Novidades, Atualizar Agora e um botão de re-verificação ali mesmo. As Novidades mostram as notas de cada release entre a sua versão e a nova, e Ajuda → Notas da Versão tem o histórico completo a qualquer momento.

Sistema

AjusteO que faz
Default Markdown app Mostra qual app abre arquivos .md hoje; Tornar o PullMark o Padrão reivindica o vínculo com um clique. Se uma atualização futura fizer o macOS derrubá-lo, o PullMark percebe e se oferece para retomá-lo.
Command line Instala o comando pullmark em /usr/local/bin para instalações via DMG (usuários do Homebrew já o têm). Mostra uma marca quando um pullmark já está no seu PATH.
Prévias do Quick Look Renderizado (o padrão) ou Código-Fonte — o que pressionar espaço no Finder mostra para arquivos Markdown.

Experimental

Lendo isto onde o PullMark (0.28.1+) está instalado? Abra a aba Experimental.

Recursos lançados antes de o design assentar, cada um rotulado beta ou alfa — o contrato de níveis explica o que cada um promete. Recursos alfa ficam ocultos até você ativar Mostrar recursos alfa (um diálogo explica os termos do alfa primeiro), e cada recurso tem seu próprio interruptor. As notas de margem moram aqui — beta desde a 0.35 e ativadas por padrão, com seu interruptor, o ajuste de autor e um botão Copiar para o trecho de instruções para agentes; o primeiro uso apresenta o recurso e oferece desligá-lo.

Onde as coisas ficam guardadas

Todas as preferências vivem no domínio de defaults app.pullmark.PullMark. Sessões, posições de leitura e rascunhos são apenas metadados — o PullMark nunca copia seus documentos para lugar nenhum, e o conteúdo buscado do GitHub fica em memória.
