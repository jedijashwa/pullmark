GitHub

AjusteO que faz
Connection Se o PullMark consegue falar com o GitHub, como quem, e por qual fonte de credenciais ("Connected as you · GitHub CLI"). Check Again relê as credenciais — depois de gh auth login, ele conecta sem reabrir o app — e Set Up… abre um passo a passo que detecta o que falta neste Mac. Atualizações

AjusteO que faz
Show What's New after an update Ligado (o padrão) apresenta as notas da versão depois que uma atualização chega; desligado troca por um banner discreto "Updated to PullMark X" com as notas a um clique — uma atualização sempre se anuncia de algum jeito.
Updates Check for Updates… sob demanda; o PullMark também verifica na abertura e periodicamente. Quando uma atualização já é conhecida, a linha oferece What's New, Update Now e um botão de re-verificação ali mesmo. O What's New mostra as notas de cada release entre a sua versão e a nova, e Help → Release Notes tem o histórico completo a qualquer momento.

Sistema

AjusteO que faz
Default Markdown app Mostra qual app abre arquivos .md hoje; Make PullMark the Default reivindica o vínculo com um clique. Se uma atualização futura fizer o macOS derrubá-lo, o PullMark percebe e se oferece para retomá-lo.
Command line Instala o comando pullmark em /usr/local/bin para instalações via DMG (usuários do Homebrew já o têm). Mostra uma marca quando um pullmark já está no seu PATH.
Quick Look previews Rendered (o padrão) ou Raw Source — o que pressionar espaço no Finder mostra para arquivos Markdown.

O seletor Light · Dark · System fica no topo — o app inteiro acompanha, cromo e páginas renderizadas por igual (cada tema traz seus próprios visuais claro e escuro). Abaixo dele, as opções visuais:

Cada escolha aqui é um cartão com prévia ao vivo, renderizada pelo pipeline de verdade — o que você vê é o que os documentos recebem.

Theme ↗

TemaVisual
GitHub (padrão)O visual clássico, exatamente como no github.com.
EditorialTítulos serifados, de livro, sobre papel quente.
TerminalMonoespaçado com um acento verde-fósforo.

Temas personalizados: solte arquivos .css na pasta Themes (botão nesta aba) e eles aparecem como cartões. Aplicam-se sobre o visual GitHub, seguem a aparência Light/Dark e reestilizam os diffs também. As prévias do Quick Look seguem seu tema (temas personalizados recuam para sua base GitHub lá).

Content width ↗

EscolhaSignificado
Standard (padrão)Uma medida clássica de leitura, como a de um livro.
WideLinhas mais longas, mais na tela — ainda limita o comprimento da linha.
Full WidthO texto usa a janela inteira — útil em tela cheia.

Vale em todo lugar, ao vivo, e compõe com temas, blame, diffs e zoom. Também alternável no meio da leitura em View → Content Width.

Line numbers ↗

EscolhaSignificado
Hidden (padrão)Uma margem limpa; números sob demanda na visão Source.
ShownA linha inicial de cada bloco no código-fonte, na margem de documentos renderizados e diffs — passe o mouse sobre um número para o intervalo completo do bloco. A numeração é por bloco, não por linha visual (o texto renderizado quebra livremente). A visão do código-fonte cru sempre mostra os próprios números de linha.

Experimental

Lendo isto onde o PullMark (0.28.1+) está instalado? Abra a aba Experimental.

Recursos lançados antes de o design assentar, cada um rotulado beta ou alfa — o contrato de níveis explica o que cada um promete. Recursos alfa ficam ocultos até você ativar Show alpha features (um diálogo explica os termos do alfa primeiro), e cada recurso tem seu próprio interruptor. As notas de margem moram aqui — beta desde a 0.35 e ativadas por padrão, com seu interruptor, o ajuste de autor e um botão Copy para o trecho de instruções para agentes; o primeiro uso apresenta o recurso e oferece desligá-lo.

Onde as coisas ficam guardadas

Todas as preferências vivem no domínio de defaults app.pullmark.PullMark. Sessões, posições de leitura e rascunhos são apenas metadados — o PullMark nunca copia seus documentos para lugar nenhum, e o conteúdo buscado do GitHub fica em memória.
