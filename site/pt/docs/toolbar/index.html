A barra de ferramentas

Uma barra por tipo de visão, cada uma totalmente personalizável: clique nela com o botão direito (ou View → Customize Toolbar…) e arraste itens para fora, reorganize-os, adicione o que começa oculto. Cada visão lembra seu próprio arranjo entre as aberturas do app.

Como funciona a personalização

O PullMark não tem uma barra de ferramentas — tem uma por tipo de visão, do mesmo jeito que a janela de composição do Mail mantém uma barra diferente da janela principal. Você personaliza a barra que está vendo: abra um arquivo de pull request para personalizar a barra de arquivo de PR, um documento local para personalizar a barra de arquivo local. A paleta só oferece os itens que existem onde você a abriu.

Tudo na paleta é permitido — remova, reordene, solte um Flexible Space (espaço flexível) para afastar os grupos. Itens marcados como oculto abaixo começam na paleta, não na barra. O único lugar aonde itens não vão é a faixa da própria barra lateral, ao lado do botão de alternância: aquela seção pertence ao sistema, e o que for solto lá se acomoda no início da seção principal. Restaure qualquer barra arrastando o conjunto padrão de volta, do rodapé da paleta.

A visão geral do PR e docs de repositório navegados de um PR

A visão geral se mantém mínima: Share (a página do pull request no GitHub) mais os itens de toda visão. Um documento de repositório navegado a partir do conteúdo de um PR carrega Blame e Outline, com os itens de zoom e o Content Width na sua paleta.
