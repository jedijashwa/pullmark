ドキュメント

PullMark を、文書で読む

アプリのすることすべてを、書き留めました。機能のツアー、すべての設定と ショートカットのリファレンス、サイドバーの各アイコンの意味、pullmark コマンド、 そして数少ないつまずきどころの直し方。

  • 機能

    ガイド付きツアー——読む、PR の差分をレビューする、GitHub のリンクと リポジトリ、その場での編集、書き出し。

  • サイドバー

    Open Files、プレビュー、Locations、Pull Requests、Recents——そして すべてのアイコンとチップの意味。

  • 設定

    ⌘, の中のすべてのコントロール——General、Appearance、Keyboard—— デフォルト値と、それぞれが変えるもの。

  • キーボードショートカット

    キーマップの全体。どのショートカットをどう割り当て直せるかも。

  • コマンドライン

    pullmark コマンド。ファイル、フォルダ、ワークツリー、 スクリプトから使うときのメモ。

  • トラブルシューティング

    エラーメッセージの解説に、定番の話題——Gatekeeper、GitHub 認証、 アップグレード後の Quick Look。

  • 実験的機能

    設計が固まる前に出荷される機能たち。アルファまたはベータのラベル付きで、 いまはマージンノートがここに——フォーマット仕様とエージェント向けの指示も含めて。

はじめての方へ

フロントページに短い紹介とインストール方法があります。5 分コースは こうです。インストールし、適当な .md ファイル（またはそのフォルダ）を開き、 GitHub の PR URL（あるいは github.com/…/blob/… のリンク）を貼り付けて、 レンダリングされるのを眺める。その先は機能ツアーが 引き継ぎます。
