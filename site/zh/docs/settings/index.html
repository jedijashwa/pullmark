设置

⌘, 背后的一切——四个标签页：“通用”管 行为，“外观”管 PullMark 的样子，“键盘”管键位表， “实验性功能”放尚在打磨的功能。窗口会在你上次用的标签页上 重新打开。

通用

正在装有 PullMark（0.28.1+）的 Mac 上读这页？打开“通用”标签页。

阅读

设置选项 · 默认作用
恢复上次会话中的文件和拉取请求 开/关 — 开 重新打开 PullMark 上次退出时侧边栏里的内容——文件、文件夹、 PR、浏览中的仓库，以及预览条目（依旧作为预览）。
显示隐藏文件开/关 — 关 在“位置”中显示点文件和隐藏文件夹——.github/ 文档之类。也可用 ⇧⌘.（Finder 同款组合键）或 “显示 → 显示隐藏文件”切换；每次切换，所有打开的“位置” 都会重新扫描。
GitHub Markdown 链接 首次点击时询问 · 在 PullMark 中打开 · 在浏览器中打开 — 首次点击时询问 点击指向 GitHub 上 Markdown 文件的链接时会发生什么。按住 ⌘ 点击执行另一种行为。首次点击对话框里的“记住我的选择” 勾选框会替你设置此项。
点击“位置”中的文件 先预览 · 完整打开 — 先预览 “先预览”让单击即可查看文件而不保留它——一条斜体条目 （在“打开的文件”中，或在其 GitHub 仓库之下），下一次预览就替换； 双击或开始编辑才保留。“完整打开”则保留你点过的每个文件。对本地 文件夹和浏览中的 GitHub 仓库一视同仁。见 预览。

审查

设置选项 · 默认作用
默认差异布局内联 · 并排 — 内联 PR 渲染差异的打开方式。可用 ⌥⌘L 按文件翻转。
在边栏中显示审查请求开/关 — 开 “审查请求”子分组：请求你审查的开放 PR。未登录时无论 如何都不显示。
仅显示改动 Markdown 的请求开/关 — 开 隐藏不含 Markdown 文件的审查请求——PullMark 对它们无可 展示。
在 PR 总览上显示审查讨论开/关 — 开 在总览的会话里，把行内审查会话嵌在所属审查之下——每条会话 都在，包括 PullMark 不渲染的文件，被评论的段落一并显示。关闭则 只显示结论与评论。0.34 起从“实验性功能”毕业。

GitHub

设置作用
连接 PullMark 能否连上 GitHub、以谁的身份、经由哪个凭据来源 （“已连接为 你 · GitHub CLI”）。重新检查 重新读取 凭据——gh auth login 之后无需重启即可连上—— 设置… 打开一个引导流程，检测这台 Mac 还缺什么。 完整的凭据故事见 GitHub 访问。

更新

设置作用
更新后显示“新增功能” 开启（默认）时，更新落地后展示发行说明；关闭则换成一条安静的 “已更新到 PullMark X”横幅，说明一键可达——更新总会以某种方式 宣告自己。
更新 检查更新… 随时手动检查；PullMark 也 会在启动时和定期检查。已知有更新时，这一行直接提供 新增功能、立即更新 和一个 重新检查按钮。“新增功能”展示你当前版本到新版本之间每个版本的 说明，帮助 → 发行说明 随时可看完整 历史。

系统

设置作用
默认 Markdown 应用 显示当前由哪个应用打开 .md 文件； 把 PullMark 设为默认一键认领绑定。此后若 某次升级让 macOS 丢了它，PullMark 会发现并主动提出拿回来。
命令行 为 DMG 安装把 pullmark 命令装进 /usr/local/bin（Homebrew 用户已经有了）。 PATH 上已有 pullmark 时显示对勾。
快速查看预览 渲染后（默认）或原始源码——在 Finder 里按空格看到的 Markdown 是哪一种。

外观

正在装有 PullMark（0.28.1+）的 Mac 上读这页？打开“外观”标签页。

浅色 · 深色 · 跟随系统的开关在最上面——整个应用一起变，窗口和 渲染页面皆然（每套主题自带浅色与深色两副面孔）。往下是视觉选项：

这里的每个选择都是一张带实时预览的卡片，由真实渲染管线渲染—— 你看到的就是文档将得到的。

主题↗

主题外观
GitHub （默认）经典外观，与 github.com 上一模一样。
Editorial温暖纸面上的书卷气衬线标题。
Terminal等宽字体，配一抹磷光绿。

自定义主题：把 .css 文件放进 Themes 文件夹（本标签页有按钮），它们就会以卡片出现。自定义主题叠加在 GitHub 外观之上，跟随浅色/深色外观，也会重新装点差异。快速查看 预览跟随你的主题（自定义主题在那里回落到它们的 GitHub 基底）。

栏宽↗

选项含义
Standard （默认）经典的书本式阅读行长。
Wide更长的行，屏幕上更多内容——行长仍有上限。
Full Width文字用满整个窗口——全屏时很好用。

处处生效、即时生效，与主题、blame、差异和缩放都能叠加。阅读中 也可以从“显示 → 栏宽”切换。

行号↗

选项含义
已隐藏 （默认）干净的页边；需要时“源码”视图里随时有行号。
已显示渲染文档与差异的页边显示每个区块起始的源码 行号——悬停一个数字可见区块的完整范围。编号按区块而非视觉行 （渲染文本自由折行）。原始源码视图始终显示自己的行号。

键盘

正在装有 PullMark（0.28.1+）的 Mac 上读这页？打开“键盘”标签页。

每个菜单动作的快捷键都可以重新绑定——完整键位表，以及录制、 冲突和“恢复默认”的工作方式，见 键盘快捷键。

实验性功能

正在装有 PullMark（0.28.1+）的 Mac 上读这页？打开“实验性功能”标签页。

设计尚未定稿就先行发布的功能，各自标注 beta 或 alpha—— 级别契约解释了各自承诺什么。 Alpha 功能在你打开 显示 alpha 功能 之前保持隐藏 （会先有对话框说明 alpha 条款），每个功能都有自己的启用开关。 页边批注就住在这里—— 0.35 起为 beta 且默认开启，带自己的开关、作者设置，和一枚复制 智能体指令片段的“拷贝”按钮；第一次使用会介绍这个功能，并提供关闭的 选项。

数据存在哪里

所有偏好设置都存放在 app.pullmark.PullMark 默认值域。 会话、阅读位置和草稿都只是元数据——PullMark 从不把你的文档复制到 任何地方，从 GitHub 抓取的内容只待在内存里。
