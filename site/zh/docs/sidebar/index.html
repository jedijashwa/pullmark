文档

侧边栏

四个分区，按事物的含义组织，而不是按 来源：你打开了什么、你浏览的地方、你在审查的拉取请求，以及你去过 哪里。

Open Files（打开的文件）

工作集：每一份你明确打开过的文档——来自 Finder、拖放、⌘O、 命令行，或从某个 Location 保留下来的文件。 平铺排列，可拖动排序，悬停任意一行出现 ✕ 即可移除（选中行按 ⌫ 亦可）。 右键分区标题有 Close All（全部关闭）。

预览

在 Location 里单击一个文件，它立即渲染——并以预览的身份 出现在 Open Files 中：一条斜体条目，始终排在分区最后。再点另一个文件， 预览条目就被替换，所以浏览一棵大树永远不会堆出一摞行。这与 VS Code 的 预览标签页或 Xcode 的临时编辑器是同一个思路，连斜体都一样。

当你对一份预览表现出阅读之外的投入，它就转正为普通的固定条目：

  • 双击树里的文件，或双击那条斜体条目本身
  • 开始编辑——进入 Edit Mode（编辑模式）或保存一次 区块编辑都会把它固定
  • 右键菜单里的 Keep Open（保持打开）

阅读性的动作——blame、行历史、细看图片或图表——刻意不会转正预览。 如果你更希望每次点击都完整打开文件，请在设置里改 Clicking files in Locations。

远程仓库以同样的方式、在同样的位置预览。浏览 GitHub 仓库的文件树，或跟随远程文档内部的链接，会在 Open Files 中放同一条 斜体条目——带书本图标和 owner/repo @ ref 的第二行，因为 文件不在你的 Mac 上。每个窗口永远只有一条预览，本地远程皆然： 预览任何新内容都会替换你之前预览的东西。保留一份远程文档（双击或 Keep Open）才把它归档到它的仓库——它会移到 Locations 中该仓库的固定 列表里。⌘K 打开的内容直接固定，因为粘贴 URL 是明确的意图。

任何位于已打开 Location 内的 Open Files 行，右键菜单里都有 Reveal in Location（在位置中显示）——从“我在读什么” 跳回“它住在哪里”。

Locations（位置）

可浏览的根，无论它们住在哪里。两种行共享这一分区，靠图标区分：

行含义
📁 文件夹图标本地文件夹——其中的 Markdown 文件以树呈现 （或平铺列表；右键 → View as List）。持续监视变化。
📕 书本图标为浏览而打开的 GitHub 仓库——从 API 抓取， 不写盘。

本地文件夹若是 git 检出，会长出一枚分支标签 （分支符号 + 名称）；若其远端在 GitHub 上，还会出现一个小小的合上书本 标记——悬停可见对应哪个仓库。点击分支标签打开分支与工作树菜单：

  • Worktrees（工作树）——仓库的每个工作树，当前行 对应的那个打勾；选择另一个即作为独立 Location 打开。PullMark 从不 检出或切换工作树——它只是打开已经在那里的文件夹。
  • View Branch from GitHub（从 GitHub 查看分支）—— 远程读取另一个分支的文件，不动你的检出。已有本地工作树的分支会 跳到那个工作树——本地优先于远程。
  • Open on GitHub（在 GitHub 上打开）——在浏览器里 打开该仓库（当前分支）。

在远程（书本图标）仓库上，同一枚标签列出分支：Switch To （切换到）把会话重新钉到另一个分支，按住 ⌥ 则出现 Open Branch Separately（单独打开分支）供并排阅读。 Browse Repo Files…（浏览仓库文件…）载入仓库完整的 Markdown 树。仓库保留的文档排在树上方，永远不会淹没在大仓库里； 已在树中可见的保留文档就在树里表示。（仅在预览的文档显示在 Open Files，不在这里。）

路径解析不了的文件夹（未挂载的卷、被删除的工作树）会变暗并带上 问号角标，而不是消失——路径回来时它自己复活。

Pull Requests（拉取请求）

每个打开的 PR 是一组：先是总览行（状态图标 + 改动的 Markdown 数量），然后是它改动的 Markdown 文件——带计数的评论气泡标记着有 未解决审查会话的文件。在你打开的 PR 之下，Review Requests （审查请求）收集等待你审查的 PR，未读计数即使折叠也保持可见 （可在设置中隐藏，也可只显示涉及 Markdown 的 PR）。

PR 行的状态图标：

状态图标
草稿拉取请求箭头，灰色
打开拉取请求箭头，绿色
已合并合并箭头，紫色
已关闭✕ 圆圈，红色
不可用垃圾桶，灰色——PR（或你的访问权限）不在了

PR 内的逐文件标记：绿色 + 圆圈为新增，红色 − 圆圈为删除，→ 圆圈为重命名， 铅笔圆圈为修改。

Recents（最近使用）

最近打开、且没有在上方出现的文件、文件夹和拉取请求。PR 条目带着 实时状态图标；文件已丢失的最近条目会变暗（时钟角标）而不是消失， 路径回来时复活——为切换分支和未挂载的卷而生。右键分区标题可 Clear Recents（清除最近使用）。

移除

悬停任意顶层行出现 ✕——它把行从侧边栏移走，绝不删除磁盘或 GitHub 上的任何东西。选中行按 ⌫ 效果相同。Location 树内的文件没有 ✕： 它们是一个地方的内容，不是侧边栏条目。

图标含义
文档一个 Markdown 文件
文档，名称为斜体预览——你的下一次单击就会替换它
文件夹本地文件夹或目录
文件夹 + ?此刻找不到的文件夹——变暗，会复活
文档 + 时钟文件已丢失的最近条目
合上的书本一个 GitHub 仓库（作为行图标：正在远程浏览； 作为行尾小标记：这个本地文件夹是它的检出）

托盘Review Requests——等待你审查的 PR

分支符号只出现在真正的 git 引用上（只作标签， 绝不作文件夹图标）——文件夹是文件夹，仓库是书本，分支是分支。
