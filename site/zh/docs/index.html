PullMark，白纸黑字

这款应用能做的每一件事，都写在这里：一趟功能导览、 每个设置与快捷键的参考、侧边栏每个图标的含义、pullmark 命令， 以及少数几处可能出岔子的地方该怎么修。

  • 功能

    导览——阅读、审查 PR 差异、GitHub 链接与仓库、 原地编辑、导出。

  • 侧边栏

    “打开的文件”与预览、“位置”、 “拉取请求”、“最近使用”——以及每个图标和标签的含义。

  • 设置

    ⌘, 里的每一个控件——General（通用）、Appearance（外观） 和 Keyboard（键盘）——附默认值和每一项的作用。

  • 键盘快捷键

    完整键位表，包括哪些快捷键可以重新绑定、如何绑定。

  • 命令行

    pullmark 命令：文件、文件夹、工作树， 以及写脚本时的注意事项。

  • 疑难解答

    逐条解释错误信息，外加几个经典问题：Gatekeeper、 GitHub 认证、升级后的 Quick Look。

  • 实验性功能

    设计尚未定稿就先行发布的功能，标注 alpha 或 beta——页边批注（Margin Notes）现在就住在这里，格式规范与智能体指令 一应俱全。

第一次来？

首页有简明版介绍和安装方式。五分钟上手路径：安装， 打开任意 .md 文件或装满它们的文件夹，再粘贴一个 GitHub PR 链接 （或者就是一个 github.com/…/blob/… 链接），看它渲染出来。 接下来交给功能导览。
