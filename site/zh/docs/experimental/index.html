实验性功能

有些功能在设计定稿之前就先发布了——标签清清 楚楚，避开主路，并对自己有多稳定实话实说。它们住在 设置 → 实验性功能里， 各自佩着自己的级别。

两个级别

级别契约
beta 设计大体已定。我们切实努力在版本之间保持行为与数据格式兼容， 功能很可能从“实验性功能”毕业——但在毕业之前，一切都不算 保证。
alpha 没有任何保证，风险自担。行为和数据格式可能在版本之间不兼容地 改变——旧格式的迁移我们可能支持，也可能不支持——功能也可能被 整个移除。Alpha 功能在你打开 显示 alpha 功能 之前保持 隐藏，而那个开关生效之前会先说明这份契约。

功能可以往上走（alpha → beta → 常规功能），任何实验性功能也可能 在任何级别被撤下。无论发生哪种，发行说明都会写明。

现在的实验性功能

“审查讨论”已在 0.34 毕业（现在是常规 功能，对所有人开启，开关在 设置 ▸ 通用 ▸ 审查）， “页边批注”在 0.35 从 alpha 升到了 beta——级别机制正按设计 运转。

  • 页边批注beta

    像评论 PR 一样评论任何本地 Markdown 文档—— 批注保存进文件本身，格式智能体读得懂。默认开启：你第一次伸手 用它时，PullMark 会介绍这个功能并提供关闭的选项。附带格式规范 和给智能体的指令片段。

试用

打开设置 → 实验性功能。Beta 功能 就列在那里；alpha 功能要等你打开 显示 alpha 功能 并接受 alpha 的含义之后才出现（只有确实有功能处在 alpha 级别时，这个开关 才存在）。每个功能都有自己的启用开关。Alpha 功能从不默认开启； beta 功能可以——“页边批注”就是——那样的话，第一次使用会做一次 介绍，介绍里就带着“关闭”按钮。

正在装有 PullMark（0.28.1+）的 Mac 上读这页？ 现在就打开 设置 → 实验性功能。

反馈

实验性功能正因为早期用户的反馈而改变。 提一个 issue——“帮助 → 报告 Bug…”会预填你的 版本号。
