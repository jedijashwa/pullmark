工具栏

每种视图一条工具栏，全都可以自定义：右键点它 （或 View → Customize Toolbar…），把项目拖走、重新排列、加入初始 隐藏的项目。每个视图跨启动记住自己的排布。

自定义的原理

PullMark 没有“一条”工具栏——它给每种视图各配一条，就像 Mail 的 撰写窗口和主窗口各有各的工具栏。你自定义的是眼前这一条：打开一个 拉取请求文件，自定义的就是 PR 文件工具栏；打开本地文档，自定义的 就是本地文件工具栏。面板只提供在你打开它的地方真实存在的项目。

面板里的一切都任你处置——移除、重排、放入 Flexible Space （弹性空间）把项目群推开。下方标注隐藏的项目初始待在面板里 而不在栏上。唯一放不进去的位置是侧边栏切换键旁边、属于侧边栏自己的 那一段：它归系统所有，扔过去的项目会落到主区域的最前端。把面板底部 的默认项目组拖回去，即可恢复任何一条工具栏。

每个视图都有

项目默认作用
Review（审查）显示 会变形的审查控件，仅在 PR 视图上——待提交评论数、结论、提交。 窗口收窄时它坚持得最久：其他项目折进溢出菜单后，审查状态依然 可见。
Open File or Folder（打开文件或文件夹）显示 打开本地 Markdown 或一个文件夹 Location。
Open Pull Request（打开拉取请求）显示 按 URL 打开 GitHub 拉取请求。
Appearance（外观）显示 浅色 · 深色 · 跟随系统，应用全局。

本地文件

项目默认作用
Share（共享）显示该文件的标准共享面板。
Edit（编辑）显示编辑模式——点击任意区块原地编辑。
Compare（比较）显示 与某个提交或分支比较（需要 git 仓库）。一枚小点表示文件有 未提交的改动。
Blame显示 每个区块最后由谁改动；不在仓库中时禁用。
Outline（大纲）显示标题侧边栏。
Reload（重新载入）显示从磁盘重读文件。
Source（源码）隐藏渲染页面背后的原始 Markdown。
Zoom In · Actual Size · Zoom Out隐藏 相互独立的项目——只加你用得着的那几个。
Content Width（栏宽）隐藏Standard · Wide · Full Width。
Add Margin Note（添加页边批注）隐藏 仅当页边批注 开启时出现在面板里。

GitHub 文档

直接从仓库读取的文档——经由链接、⌘K 或浏览中的仓库 Location 打开。

项目默认作用
Compare（比较）显示同一文档在另一分支上的版本，以渲染差异呈现。
Blame显示来自 GitHub API 的逐区块 blame。
Outline（大纲）显示标题侧边栏。
Share（共享）隐藏 文档的 github.com 页面——人真正想要的那个链接，绝不是 裸 URL。
Reload（重新载入）隐藏 把分支重新解析到当前最新提交并重新抓取。对钉在特定提交上 打开的文档保持禁用——并写明原因——因为那不可能再变。
Source（源码）隐藏原始 Markdown。
缩放项目 · Content Width隐藏与本地文件相同。

拉取请求文件

项目默认作用
Navigation（导航）显示 回到总览、上一个/下一个 Markdown 文件，以及 n/m 跳转菜单—— 一个整体，一次拖动。
View picker（视图选择器）显示 Rendered Diff · Source Diff · Result，居中。
Outline（大纲）显示标题侧边栏。
Layout（布局）显示 行内或并排——在 Rendered Diff 视图中可用（新文件始终以行内 渲染）。
Blame显示 在 Result 视图中可用——那里才有一份完成的文档可以注解。
Comment on File（评论文件）显示 针对文件整体、而非某一行的评论。
缩放项目 · Content Width隐藏与本地文件相同。

PR 总览，以及从 PR 浏览的仓库文档

总览保持精简：Share（拉取请求的 GitHub 页面）加上 每个视图都有的项目。从 PR 内容浏览到的仓库文档带 Blame 和 Outline，缩放项目和 Content Width 收在它的面板里。
