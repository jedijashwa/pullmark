Ajustes

Todo lo que hay detrás de ⌘, — cuatro pestañas: General para el comportamiento, Appearance (apariencia) para el aspecto de PullMark, Keyboard (teclado) para el mapa de teclas y Experimental para las funciones aún por asentar. La ventana reabre en la última pestaña que usaste.

Actualizaciones

AjusteQué hace
Show What's New after an update Activado (por defecto) presenta las notas de la versión cuando llega una actualización; desactivado lo sustituye por un discreto aviso «Updated to PullMark X» con las notas a un clic — una actualización siempre se anuncia de algún modo.
Updates Check for Updates… a demanda; PullMark también comprueba al abrir y periódicamente. Cuando ya se conoce una actualización, la fila ofrece What's New, Update Now y un botón de recomprobar ahí mismo. What's New muestra las notas de cada versión entre la tuya y la nueva, y Help → Release Notes guarda el historial completo en todo momento.

TemaAspecto
GitHub (por defecto)El aspecto clásico, exactamente como en github.com.
EditorialEncabezados con serifa de libro sobre papel cálido.
TerminalMonoespaciada con un acento verde fósforo.

Temas personalizados: suelta archivos .css en la carpeta Themes (hay un botón en esta pestaña) y aparecen como tarjetas. Se aplican sobre el aspecto GitHub, siguen la apariencia Light/Dark y reestilizan también los diffs. Las vistas previas de Quick Look siguen tu tema (los temas personalizados recurren ahí a su base GitHub).

Content width (ancho del contenido) ↗

OpciónSignificado
Standard (por defecto)La medida de lectura clásica de un libro.
WideLíneas más largas, más en pantalla — sigue limitando el largo de línea.
Full WidthEl texto usa toda la ventana — útil en pantalla completa.

Se aplica en todas partes, en vivo, y se compone con los temas, el blame, los diffs y el zoom. También conmutable en plena lectura desde View → Content Width.

Line numbers (números de línea) ↗

OpciónSignificado
Hidden (por defecto)Un margen limpio; números a demanda en la vista Source.
ShownLa línea de origen inicial de cada bloque en el margen de los documentos renderizados y los diffs — pasa el cursor por un número para el rango completo del bloque. La numeración es por bloque, no por línea visual (el texto renderizado fluye libre). La vista de código fuente crudo siempre muestra sus propios números de línea.

Experimental

¿Lees esto donde PullMark (0.28.1+) está instalado? Abre la pestaña Experimental.

Funciones que se publican antes de que su diseño esté asentado, cada una etiquetada beta o alfa — el contrato de niveles explica qué promete cada uno. Las funciones alfa permanecen ocultas hasta que activas Show alpha features (antes, un diálogo explica las condiciones del alfa), y cada función tiene su propio interruptor. Las notas al margen viven aquí — en beta desde la 0.35 y activadas por defecto, con su interruptor, el ajuste de autor y un botón Copy para el fragmento de instrucciones del agente; el primer uso presenta la función y ofrece desactivarla.

Dónde se guarda todo

Todas las preferencias viven en el dominio de defaults app.pullmark.PullMark. Las sesiones, las posiciones de lectura y los borradores son solo metadatos — PullMark nunca copia tus documentos a ningún sitio, y el contenido descargado de GitHub se queda en memoria.
