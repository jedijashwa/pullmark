Ajustes

Todo lo que hay detrás de ⌘, — cuatro pestañas: General para el comportamiento, Apariencia para el aspecto de PullMark, Teclado para el mapa de teclas y Experimental para las funciones aún por asentar. La ventana reabre en la última pestaña que usaste.

Actualizaciones

AjusteQué hace
Mostrar Novedades después de una actualización Activado (por defecto) presenta las notas de la versión cuando llega una actualización; desactivado lo sustituye por un discreto aviso «Actualizado a PullMark X» con las notas a un clic — una actualización siempre se anuncia de algún modo.
Actualizaciones Buscar actualizaciones… a demanda; PullMark también comprueba al abrir y periódicamente. Cuando ya se conoce una actualización, la fila ofrece Novedades, Actualizar ahora y un botón de recomprobar ahí mismo. Novedades muestra las notas de cada versión entre la tuya y la nueva, y Ayuda → Notas de la versión guarda el historial completo en todo momento.

Sistema

AjusteQué hace
App por defecto para Markdown Muestra qué app abre ahora mismo los archivos .md; Hacer que PullMark sea la app por defecto reclama el vínculo con un clic. Si una actualización posterior hace que macOS lo suelte, PullMark lo nota y ofrece recuperarlo.
Línea de comandos Instala el comando pullmark en /usr/local/bin para las instalaciones por DMG (los usuarios de Homebrew ya lo tienen). Muestra una marca cuando ya hay un pullmark en tu PATH.
Vistas previas de Quick Look Renderizado (por defecto) o Código fuente crudo — lo que muestra pulsar espacio en el Finder para archivos Markdown.

Experimental

¿Lees esto donde PullMark (0.28.1+) está instalado? Abre la pestaña Experimental.

Funciones que se publican antes de que su diseño esté asentado, cada una etiquetada beta o alfa — el contrato de niveles explica qué promete cada uno. Las funciones alfa permanecen ocultas hasta que activas Mostrar las funciones alfa (antes, un diálogo explica las condiciones del alfa), y cada función tiene su propio interruptor. Las notas al margen viven aquí — en beta desde la 0.35 y activadas por defecto, con su interruptor, el ajuste de autor y un botón Copiar para el fragmento de instrucciones del agente; el primer uso presenta la función y ofrece desactivarla.

Dónde se guarda todo

Todas las preferencias viven en el dominio de defaults app.pullmark.PullMark. Las sesiones, las posiciones de lectura y los borradores son solo metadatos — PullMark nunca copia tus documentos a ningún sitio, y el contenido descargado de GitHub se queda en memoria.
