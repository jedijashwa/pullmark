docs

PullMark, documentado

Todo lo que hace la app, por escrito: un recorrido por las funciones, una referencia de cada ajuste y cada atajo, qué significa cada icono de la barra lateral, el comando pullmark y los arreglos para las pocas cosas que pueden torcerse.

  • Funciones

    El recorrido guiado — leer, revisar diffs de PR, enlaces y repos de GitHub, editar en el sitio, exportar.

  • La barra lateral

    Open Files, vistas previas, Locations, Pull Requests, Recents — y qué significa cada icono y cada chip.

  • Ajustes

    Cada control detrás de ⌘, — General, Appearance y Keyboard — con sus valores por defecto y qué cambia cada uno.

  • Atajos de teclado

    El mapa de teclado completo, incluidos qué atajos puedes reasignar y cómo.

  • Línea de comandos

    El comando pullmark: archivos, carpetas, worktrees y notas para scripts.

  • Solución de problemas

    Los mensajes de error explicados, más los clásicos: Gatekeeper, la autenticación de GitHub, Quick Look tras una actualización.

  • Funciones experimentales

    Funciones que se publican antes de que su diseño esté asentado, etiquetadas alfa o beta — las notas al margen viven aquí ahora, con especificación e instrucciones para agentes incluidas.

¿Primera vez por aquí?

La página principal tiene la versión corta y la instalación. El camino de cinco minutos: instala, abre cualquier archivo .md o una carpeta llena de ellos, luego pega la URL de un PR de GitHub (o simplemente un enlace github.com/…/blob/…) y míralo renderizarse. El recorrido por las funciones continúa desde ahí.
