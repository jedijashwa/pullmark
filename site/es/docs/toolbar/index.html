La barra de herramientas

Una barra de herramientas por tipo de vista, todas totalmente personalizables: haz clic derecho sobre ella (o Visualización → Personalizar barra de herramientas…) y arrastra elementos fuera, reordénalos, añade lo que empieza oculto. Cada vista recuerda su propia disposición entre sesiones.

Cómo funciona la personalización

PullMark no tiene una sola barra de herramientas — tiene una por tipo de vista, igual que la ventana de redacción de Mail lleva una barra distinta de la de su ventana principal. Personalizas la barra que estás mirando: abre un archivo de pull request para personalizar la barra de archivos de PR, un documento local para la de archivos locales. La paleta solo ofrece los elementos que existen allí donde la abriste.

Todo lo de la paleta es terreno libre — quítalo, reordénalo, suelta Espacio flexible para separar grupos. Los elementos marcados oculto más abajo empiezan en la paleta y no en la barra. El único lugar al que los elementos no van es la franja propia de la barra lateral, junto a su conmutador: esa sección pertenece al sistema, y lo que sueltes ahí se acomoda al principio de la sección principal. Restaura cualquier barra arrastrando de vuelta el juego por defecto desde el fondo de la paleta.

En todas las vistas

Atrás/Adelantevisible Atrás y adelante por todos los documentos que has visto — mantén pulsada cualquiera de las flechas para ver su historial.
Reviewvisible El control de revisión camaleónico, solo en vistas de PR — número de comentarios pendientes, veredicto, envío. Es el que más aguanta en una ventana estrecha: el estado de la revisión sigue visible cuando otros elementos se pliegan en el desbordamiento.
Abrir archivo o carpetavisible Abre Markdown local o una carpeta como Ubicación.
Abrir pull requestvisible Abre un pull request de GitHub por URL.
Aparienciavisible Claro · Oscuro · Sistema, para toda la app.

Documentos de GitHub

Documentos leídos directamente de un repo — abiertos desde enlaces, ⌘K o una Ubicación de repo navegado.

ElementoPor defectoQué hace
CompararvisibleEl mismo documento en otra rama, como diff renderizado.
BlamevisibleBlame por bloque desde la API de GitHub.
EsquemavisibleLa barra lateral de encabezados.
Compartiroculto La página github.com del documento — el enlace que una persona quiere de verdad, nunca una URL cruda.
Recargaroculto Vuelve a resolver la rama a su punta actual y descarga de nuevo. Desactivado — con el motivo — para documentos abiertos en un commit concreto, que no puede cambiar.

El resumen del PR, y docs de repo navegados desde un PR

El resumen se mantiene mínimo: Compartir (la página de GitHub del pull request) más los elementos comunes a todas las vistas. Un documento de repo navegado desde el contenido de un PR lleva Blame y Esquema, con los elementos de zoom y Ancho del contenido en su paleta.
