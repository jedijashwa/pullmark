Réglages

Tout ce qui vit derrière ⌘, — quatre onglets : General (général) pour le comportement, Appearance (apparence) pour l'allure de PullMark, Keyboard (clavier) pour le plan des touches, et Experimental (expérimental) pour les fonctionnalités encore en rodage. La fenêtre se rouvre sur le dernier onglet utilisé.

General

Vous lisez ceci là où PullMark (0.28.1+) est installé ? Ouvrez l'onglet General.

Clicking files in Locations Preview First · Open Fully — Preview First Preview First montre un fichier d'un seul clic sans le garder — une entrée en italique (dans Fichiers ouverts, ou sous son dépôt GitHub) que l'aperçu suivant remplace ; double-cliquez ou commencez à éditer pour le garder. Open Fully garde chaque fichier cliqué. Vaut pour les dossiers locaux comme pour les dépôts GitHub parcourus. Voir Aperçus.

Show review requests in the sidebaractivé/désactivé — activé Le sous-groupe Review Requests : les PR ouvertes où votre révision est demandée. Masqué dans tous les cas quand vous n'êtes pas connecté.

RéglageEffet
Connection Si PullMark peut parler à GitHub, en tant que qui, et par quelle source d'identifiants (« Connected as you · GitHub CLI »). Check Again relit les identifiants — après gh auth login, la connexion s'établit sans relancer — et Set Up… ouvre un guide qui détecte ce qui manque à ce Mac. Mises à jour

RéglageEffet
Show What's New after an update Activé (le défaut), les notes de version se présentent après une mise à jour ; désactivé, une discrète bannière « Updated to PullMark X » prend le relais avec les notes à un clic — une mise à jour s'annonce toujours d'une façon ou d'une autre.
Updates Check for Updates… à la demande ; PullMark vérifie aussi au lancement et périodiquement. Quand une mise à jour est déjà connue, la ligne propose What's New, Update Now et un bouton de re-vérification sur place. What's New montre les notes de chaque version entre la vôtre et la nouvelle, et Help → Release Notes garde l'historique complet à tout moment.

Système

RéglageEffet
Default Markdown app Montre quelle app ouvre actuellement les fichiers .md ; Make PullMark the Default revendique l'association en un clic. Si une mise à jour ultérieure la fait sauter côté macOS, PullMark s'en aperçoit et propose de la reprendre.
Command line Installe la commande pullmark dans /usr/local/bin pour les installations par DMG (les utilisateurs Homebrew l'ont déjà). Affiche une coche quand un pullmark est déjà sur votre PATH.
Quick Look previews Rendered (le défaut) ou Raw Source — ce que montre la barre Espace dans le Finder pour les fichiers Markdown.

Appearance

Vous lisez ceci là où PullMark (0.28.1+) est installé ? Ouvrez l'onglet Appearance.

L'interrupteur Light · Dark · System siège en haut — toute l'app suit, chrome et pages rendues comprises (chaque thème apporte ses propres visages clair et sombre). En dessous, les options visuelles :

Chaque choix ici est une carte avec un aperçu en direct, rendu par le vrai pipeline — ce que vous voyez est ce que les documents obtiennent.

Thème ↗

ThèmeAllure
GitHub (défaut)Le look classique, exactement comme sur github.com.
EditorialDes titres serif littéraires sur papier chaud.
TerminalDu monospace avec un accent vert phosphore.

Thèmes personnalisés : déposez des fichiers .css dans le dossier Themes (bouton dans cet onglet) et ils apparaissent en cartes. Ils s'appliquent par-dessus le look GitHub, suivent l'apparence Light/Dark et restylent aussi les diffs. Les aperçus Quick Look suivent votre thème (les thèmes personnalisés y retombent sur leur base GitHub).

S'applique partout, en direct, et se compose avec les thèmes, le blame, les diffs et le zoom. Se change aussi en pleine lecture via View → Content Width.

Experimental

Vous lisez ceci là où PullMark (0.28.1+) est installé ? Ouvrez l'onglet Experimental.

Les fonctionnalités livrées avant que leur conception soit figée, chacune étiquetée bêta ou alpha — le contrat des niveaux explique ce que chacun promet. Les fonctionnalités alpha restent cachées tant que vous n'activez pas Show alpha features (un dialogue explique d'abord les termes de l'alpha), et chaque fonctionnalité a son propre interrupteur. Les notes de marge vivent ici — en bêta depuis 0.35 et activées par défaut, avec leur interrupteur, le réglage d'auteur et un bouton Copy pour l'extrait d'instructions destiné à l'agent ; la première utilisation présente la fonctionnalité et propose de la désactiver.

Où les choses sont stockées

Toutes les préférences vivent dans le domaine de defaults app.pullmark.PullMark. Sessions, positions de lecture et brouillons ne sont que des métadonnées — PullMark ne copie jamais vos documents nulle part, et le contenu récupéré depuis GitHub reste en mémoire.
