La barre d'outils

Une barre d'outils par type de vue, chacune entièrement personnalisable : clic droit dessus (ou View → Customize Toolbar…) pour sortir des éléments, les réorganiser, ajouter ce qui démarre masqué. Chaque vue mémorise sa propre disposition d'un lancement à l'autre.

Comment marche la personnalisation

PullMark n'a pas une barre d'outils — il en a une par type de vue, comme la fenêtre de rédaction de Mail garde une barre différente de sa fenêtre principale. Vous personnalisez la barre que vous regardez : ouvrez un fichier de pull request pour personnaliser la barre des fichiers de PR, un document local pour celle des fichiers locaux. La palette ne propose jamais que les éléments qui existent là où vous l'avez ouverte.

Tout ce qui est dans la palette est bon à prendre — retirez, réordonnez, glissez un Flexible Space pour écarter les groupes. Les éléments marqués masqué ci-dessous démarrent dans la palette plutôt que dans la barre. Le seul endroit où les éléments ne vont pas, c'est la bande propre à la barre latérale, à côté de sa bascule : cette section appartient au système, et ce qu'on y dépose se replace en tête de la section principale. Restaurez n'importe quelle barre en y reglissant la panoplie par défaut depuis le bas de la palette.

La vue d'ensemble de PR, et les docs de dépôt ouvertes depuis une PR

La vue d'ensemble reste minimale : Share (la page GitHub de la pull request) plus les éléments communs à toutes les vues. Un document de dépôt parcouru depuis le contenu d'une PR porte Blame et Outline, avec les éléments de zoom et Content Width dans sa palette.
