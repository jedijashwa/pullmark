Fonctionnalités expérimentales

Certaines fonctionnalités sont livrées avant que leur conception soit figée — clairement étiquetées, hors des sentiers battus, et honnêtes sur leur degré de maturité. Elles vivent dans Settings → Experimental (réglages → expérimental), chacune portant son niveau.

Les deux niveaux

NiveauLe contrat
bêta La conception est en grande partie arrêtée. Nous faisons un réel effort pour garder le comportement et les formats de données compatibles d'une version à l'autre, et la fonctionnalité a de bonnes chances de sortir d'Experimental — même si rien n'est garanti tant que ce n'est pas fait.
alpha Aucune garantie, à vos risques et périls. Le comportement et les formats de données peuvent changer de façon incompatible d'une version à l'autre — nous pourrons prendre en charge la transition des anciens formats, ou pas — et la fonctionnalité peut être retirée entièrement. Les fonctionnalités alpha restent cachées tant que vous n'activez pas Show alpha features (afficher les fonctionnalités alpha), qui explique ce contrat avant de prendre effet.

Les fonctionnalités peuvent monter en grade (alpha → bêta → fonctionnalité ordinaire), et toute fonctionnalité expérimentale peut être retirée à n'importe quel niveau. Les notes de version le disent toujours quand l'un ou l'autre arrive.

Expérimental aujourd'hui

Review Discussion est sortie du lot en 0.34 (une fonctionnalité ordinaire désormais, active pour tout le monde, avec sa bascule dans Settings ▸ General ▸ Reviewing), et Margin Notes est passée d'alpha à bêta en 0.35 — les niveaux fonctionnent comme prévu.

  • Notes de marge bêta

    Commentez n'importe quel document Markdown local comme vous commenteriez une PR — le tout enregistré dans le fichier même, dans un format que les agents savent lire. Activées par défaut : la première fois que vous tendez la main vers elles, PullMark présente la fonctionnalité et propose de la désactiver. Avec la spec du format et un extrait d'instructions pour votre agent.

Les essayer

Ouvrez Settings → Experimental. Les fonctionnalités bêta sont listées là ; les alpha apparaissent après avoir activé Show alpha features et accepté ce que signifie l'alpha (l'interrupteur n'existe que tant que quelque chose est effectivement au niveau alpha). Chaque fonctionnalité a son propre interrupteur. Les fonctionnalités alpha ne sont jamais actives par défaut ; une bêta peut l'être — les notes de marge le sont — et la première utilisation la présente alors, avec un bouton Turn Off (désactiver) directement dans la présentation.

Vous lisez ceci sur le Mac où PullMark (0.28.1+) est installé ? Ouvrez Settings → Experimental maintenant.

Retours

Les fonctionnalités expérimentales changent grâce à ce que rapportent les premiers utilisateurs. Ouvrez une issue — Help → Report a Bug… pré-remplit votre version.
