Touches fixes

Celles-ci sont câblées et ne se changent pas :

ContexteTouches
Barre latérale : retirer la ligne sélectionnée⌫
Barre latérale : Quick Look sur le fichier sélectionnéEspace (macOS 14+)
Mode édition : passer d'un bloc à l'autre↑ ↓
Mode édition : fusionner avec le bloc précédent⌫
Mode édition : abandonner les éditions de ce bloc⎋
Palettes : déplacer / ouvrir / fermer↑ ↓ ↩ ⎋
Feuille de commit et compositeurs : confirmer⌘↩
Feuilles : fermer⎋

Les touches standard du système (⌘N nouvelle fenêtre, ⌘W, ⌘Q, ⌘C/⌘V, ⌘Z…) se comportent comme macOS l'entend et restent réservées. Il n'y a délibérément pas de ⌘S — les éditions en mode édition s'écrivent sur le disque au moment où elles atterrissent.

Réassigner

Vous lisez ceci là où PullMark (0.28.1+) est installé ? Ouvrez l'onglet Keyboard.

Dans Settings → Keyboard : cliquez un raccourci (ou sélectionnez une ligne et appuyez sur ↩), puis tapez les nouvelles touches. ⌫ retire une assignation, ⎋ annule. Les raccourcis exigent ⌘ ou ⌃ (les touches de fonction peuvent rester seules) ; les combinaisons réservées au système sont refusées avec une explication, et prendre un combo déjà tenu par une autre action propose Use Anyway (utiliser quand même), qui désassigne l'ancien détenteur. Restore Defaults… remet tout en place ; chaque ligne personnalisée a aussi sa propre flèche de retour.
