Experimentelle Features

Manche Features werden ausgeliefert, bevor ihr Design fertig ist — klar gekennzeichnet, abseits des Trampelpfads und ehrlich darüber, wie fertig sie sind. Sie wohnen in Settings → Experimental, jedes mit seiner Stufe am Revers.

Die zwei Stufen

StufeDer Vertrag
beta Das Design steht weitgehend. Wir geben uns echte Mühe, Verhalten und Datenformate zwischen Versionen kompatibel zu halten, und das Feature wird wahrscheinlich aus Experimental graduieren — garantiert ist bis dahin allerdings nichts.
alpha Keine Garantien, Nutzung auf eigene Gefahr. Verhalten und Datenformate können sich zwischen Versionen inkompatibel ändern — vielleicht unterstützen wir den Übergang älterer Formate, vielleicht auch nicht — und das Feature kann ganz verschwinden. Alpha-Features bleiben versteckt, bis du Show alpha features einschaltest; dort steht dieser Vertrag, bevor er greift.

Features können aufsteigen (alpha → beta → normales Feature), und jedes experimentelle Feature kann auf jeder Stufe wieder eingestampft werden. Die Release Notes sagen immer, wenn eins von beidem passiert.

Gerade experimentell

Review Discussion ist in 0.34 graduiert (jetzt ein normales Feature, für alle an, mit seinem Schalter in Settings ▸ General ▸ Reviewing), und Margin Notes ist in 0.35 von alpha zu beta aufgestiegen — genau so sollen die Stufen wirken.

  • Randnotizen beta

    Kommentiere jedes lokale Markdown-Dokument so, wie du einen PR kommentierst — gespeichert in der Datei selbst, in einem Format, das Agenten lesen können. Standardmäßig an: Beim ersten Griff danach stellt PullMark das Feature vor und bietet an, es abzuschalten. Mit Format-Spec und einem Schnipsel voller Anweisungen für deinen Agenten.

Ausprobieren

Öffne Settings → Experimental. Beta-Features stehen gleich dort; Alpha-Features tauchen auf, sobald du Show alpha features einschaltest und akzeptierst, was alpha heißt (den Schalter gibt es nur, solange tatsächlich etwas auf Alpha-Stufe steht). Jedes Feature hat seinen eigenen Schalter. Alpha-Features sind nie standardmäßig an; ein Beta-Feature kann es sein — Randnotizen ist es — und dann stellt sich das Feature beim ersten Einsatz vor, mit einem Turn-Off-Knopf direkt in der Vorstellung.

Liest du das auf dem Mac, auf dem PullMark (ab 0.28.1) installiert ist? Settings → Experimental jetzt öffnen.

Rückmeldungen

Experimentelle Features ändern sich genau deswegen, weil frühe Nutzer melden, was ihnen auffällt. Mach ein Issue auf — Help → Report a Bug… füllt deine Version schon vor.
