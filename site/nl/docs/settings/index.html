Instellingen

Alles achter ⌘, — vier tabbladen: General (algemeen) voor gedrag, Appearance (weergave) voor hoe PullMark eruitziet, Keyboard (toetsenbord) voor de toetsenbordkaart, en Experimental (experimenteel) voor functies die nog aan het uitkristalliseren zijn. Het venster opent op het tabblad dat je het laatst gebruikte.

General

Lees je dit waar PullMark (0.28.1+) is geïnstalleerd? Open het tabblad General.

Reading

InstellingOpties · standaardWat het doet
Restore files and pull requests from the last session aan/uit — aan Heropent wat er in de zijbalk stond toen PullMark voor het laatst afsloot — bestanden, mappen, PR's, doorbladerde repo's en de preview-regel (nog steeds als preview).
Show hidden filesaan/uit — uit Dotfiles en verborgen mappen in Locations — .github/-docs en verwanten. Ook te schakelen met ⇧⌘. (de combinatie van de Finder zelf) of View → Show Hidden Files; elke open Location scant opnieuw bij het omzetten.
GitHub Markdown links Ask on first click · Open in PullMark · Open in Browser — Ask on first click Wat klikken op een link naar een Markdown-bestand op GitHub doet. Houd ⌘ ingedrukt tijdens het klikken voor het andere gedrag. Het vinkje "Remember my selection" in het dialoogvenster bij de eerste klik stelt dit voor je in.
Clicking files in Locations Preview First · Open Fully — Preview First Preview First toont een bestand met één klik zonder het vast te houden — één cursieve regel (in Open Files, of onder zijn GitHub-repo) die de volgende preview vervangt; dubbelklik of begin te bewerken om het te houden. Open Fully houdt elk bestand dat je aanklikt vast. Geldt voor lokale mappen en doorbladerde GitHub-repo's evenzeer. Zie Previews.

GitHub

InstellingWat het doet
Connection Of PullMark met GitHub kan praten, als wie, en via welke credentialbron ("Connected as you · GitHub CLI"). Check Again leest de credentials opnieuw — na gh auth login verbindt het zonder herstart — en Set Up… opent een stappenplan dat detecteert wat er op deze Mac ontbreekt. Updates

InstellingWat het doet
Show What's New after an update Aan (de standaard) toont de releasenotes nadat een update is geland; uit toont in plaats daarvan een rustige banner "Updated to PullMark X" met de notes één klik verderop — een update kondigt zichzelf altijd op de een of andere manier aan.
Updates Check for Updates… op verzoek; PullMark controleert ook bij het opstarten en periodiek. Is er al een update bekend, dan biedt de rij What's New, Update Now en een hercontroleknop, ter plekke. What's New toont de notes van elke release tussen jouw versie en de nieuwe, en Help → Release Notes heeft altijd de volledige geschiedenis.

System

InstellingWat het doet
Default Markdown app Toont welke app op dit moment .md-bestanden opent; Make PullMark the Default claimt de koppeling met één klik. Laat macOS haar bij een latere upgrade vallen, dan merkt PullMark dat en biedt aan haar terug te nemen.
Command line Installeert het pullmark-commando in /usr/local/bin voor DMG-installaties (Homebrew-gebruikers hebben het al). Toont een vinkje wanneer er al een pullmark op je PATH staat.
Quick Look previews Rendered (de standaard) of Raw Source — wat de spatiebalk in de Finder toont voor Markdown-bestanden.

Appearance

Lees je dit waar PullMark (0.28.1+) is geïnstalleerd? Open het tabblad Appearance.

De schakelaar Light · Dark · System staat bovenaan — de hele app volgt, chrome en gerenderde pagina's gelijkelijk (elk thema brengt zijn eigen lichte en donkere gedaante mee). Daaronder de visuele opties:

Elke keuze hier is een kaart met een live preview, gerenderd door de echte pipeline — wat je ziet is wat documenten krijgen.

Experimental

Lees je dit waar PullMark (0.28.1+) is geïnstalleerd? Open het tabblad Experimental.

Functies die verschijnen voordat hun ontwerp vastligt, elk gelabeld beta of alpha — het niveaucontract legt uit wat elk niveau belooft. Alpha-functies blijven verborgen tot je Show alpha features aanzet (een dialoogvenster legt eerst de alpha-voorwaarden uit), en elke functie heeft haar eigen aan/uit-schakelaar. Margin notes woont hier — beta sinds 0.35 en standaard aan, met haar schakelaar, de auteursinstelling en een Copy-knop voor het agent-instructiefragment; het eerste gebruik introduceert de functie en biedt aan haar uit te zetten.

Waar alles wordt opgeslagen

Alle voorkeuren wonen in het defaults-domein app.pullmark.PullMark. Sessies, leesposities en concepten zijn alleen metadata — PullMark kopieert je documenten nooit ergens naartoe, en inhoud die van GitHub wordt opgehaald blijft in het geheugen.
