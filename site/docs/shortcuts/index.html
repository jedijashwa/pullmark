These are built in and can't be changed:

System-standard keys (⌘N new window, ⌘W, ⌘Q, ⌘C/⌘V, ⌘Z…) behave as macOS intends and stay reserved. There's deliberately no ⌘S — edit-mode commits write to disk as they land.

Rebinding

Reading this where PullMark (0.28.1+) is installed? Open the Keyboard tab.

In Settings → Keyboard: click a shortcut (or select a row and press ↩), then type the new keys. ⌫ removes a binding, ⎋ cancels. Shortcuts need ⌘ or ⌃ (function keys can stand alone); system-reserved combos are refused with an explanation, and taking a combo another action holds offers Use Anyway, which unbinds the previous owner. Restore Defaults… puts everything back; each customized row also has its own revert arrow.
