docs

PullMark, documented

Everything the app does, written down: a tour of the features, a reference for every setting and shortcut, what each sidebar icon means, the pullmark command, and the fixes for the few things that can go sideways.

  • Features

    The guided tour — reading, reviewing PR diffs, GitHub links and repos, editing in place, exporting.

  • The Sidebar

    Open Files, previews, Locations, Pull Requests, Recents — and what every icon and chip means.

  • Settings

    Every control in ⌘, — General, Appearance, and Keyboard — with defaults and what each one changes.

  • Keyboard Shortcuts

    The full key map, including which shortcuts you can rebind and how.

  • Command Line

    The pullmark command: files, folders, worktrees, and scripting notes.

  • Troubleshooting

    Error messages explained, plus the classics: Gatekeeper, GitHub auth, Quick Look after an upgrade.

  • Experimental Features

    Features that ship before their design is settled, labeled alpha or beta — margin notes live here now, spec and agent instructions included.

New here?

The front page has the short version and the install. The five-minute path: install, open any .md file or a folder of them, then paste a GitHub PR URL (or just a github.com/…/blob/… link) and watch it render. The features tour picks up from there.
