Beta features

The beta channel ships features while they're still settling — same app, early versions. Betas are signed and notarized exactly like stable releases; what's "beta" is the feature design, which may shift with feedback before it reaches everyone.

Getting the beta

In PullMark 0.27.1 or later, flip Settings → General → Update channel to Beta — the update banner then offers the newest release of either kind, and Check for Updates… will bring you the current beta right away. Switching back to Stable quietly rides you onto stable at the next ordinary release. Stable-channel installs never see pre-releases — GitHub's own releases/latest excludes them, so nothing beta can reach the stable channel by accident.

Prefer Homebrew to manage it? The beta is its own cask (the two conflict on purpose — they install the same app):

brew uninstall --cask pullmark   # if the stable cask is installed
brew install --cask jedijashwa/tap/pullmark@beta

Or download the latest pre-release DMG from GitHub releases — betas are marked Pre-release there.

Going back to stable

Set the update channel to Stable and the next stable release replaces your beta through the normal update banner. In a hurry, with Homebrew:

brew uninstall --cask pullmark@beta
brew install --cask jedijashwa/tap/pullmark

Your files are never at risk either way — PullMark's only state is preferences and your sidebar session, and both carry across channels unchanged.

Feedback

Beta features change because of what beta users report. Open an issue — mention the beta version from PullMark → About.
