Experimental features

Some features ship before their design is settled — clearly labeled, off the beaten path, and honest about how settled they are. They live in Settings → Experimental, each wearing its level.

The two levels

LevelThe contract
beta The design is mostly settled. We make a real effort to keep behavior and data formats compatible between versions, and the feature is likely to graduate out of Experimental — though nothing is guaranteed until it does.
alpha No guarantees, use at your own risk. Behavior and data formats may change incompatibly between versions — we may support transitioning older formats, or may not — and the feature may be removed entirely. Alpha features stay hidden until you turn on Show alpha features, which explains this contract before it takes effect.

Features can move up (alpha → beta → a regular feature), and any experimental feature can be pulled at any level. Release notes always say when either happens.

Experimental now

Review Discussion graduated in 0.34 (a regular feature now, on for everyone, with its toggle in Settings ▸ General ▸ Reviewing), and Margin Notes moved up from alpha to beta in 0.35 — the levels working as intended.

  • Margin Notes beta

    Comment on any local Markdown document the way you'd comment on a PR — saved into the file itself, in a format agents can read. On by default: the first time you reach for it, PullMark introduces the feature and offers to turn it off. Includes the format spec and an instructions snippet for your agent.

Trying them

Open Settings → Experimental. Beta features are listed right there; alpha features appear after you turn on Show alpha features and accept what alpha means (the switch only exists while something is actually at the alpha level). Each feature has its own enable switch. Alpha features are never on by default; a beta feature can be — Margin Notes is — and then the first use introduces it, with a Turn Off button right in the introduction.

Reading this on the Mac where PullMark (0.28.1+) is installed? Open Settings → Experimental now.

Feedback

Experimental features change because of what early users report. Open an issue — Help → Report a Bug… pre-fills your version.
